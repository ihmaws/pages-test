Frequently Asked Questions

Is Example free?

Yes. This is a dummy product, so it's as free as it gets.

What platforms are supported?

macOS, Linux, and Windows, as long as a supported Node.js version is installed.

Can I use a custom domain?

Yes. Set the domain field in example.config.json and point your DNS at the target.

How do I roll back a publish?

Each publish is versioned. Roll back to the previous version with:

example rollback

Where do I report a bug?

Nowhere — this is a fictional product used to test GitHub Pages. In a real guide, this is where you'd link an issue tracker or support inbox.
