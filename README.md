# Example CLI

A command-line tool for packaging, previewing, and publishing static sites.
This repository is a test project for GitHub Pages.

## Repository layout

| Path | Purpose |
|------|---------|
| `src/` | Application source code. |
| `docs/` | User guide, published via GitHub Pages. |
| `package.json` | Project metadata and scripts. |

## Documentation

The user guide is published with GitHub Pages from the `docs/` folder:

**https://ihmaws.github.io/pages-test/**

## Development

```bash
npm install
npm start
```
