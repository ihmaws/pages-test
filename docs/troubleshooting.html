Troubleshooting

Common issues and how to resolve them.

command not found: example

The global install directory isn't on your PATH. Confirm where npm installs global binaries: 

npm bin -g

Add that directory to your PATH and restart your shell.

Preview server won't start

Usually the port is already in use. Start the preview on a different port: 

example preview --port 4100

Publish fails with "target not found"

The target named in example.config.json doesn't exist or isn't reachable. Check the config, then confirm the target with: 

example targets list
Still stuck? Re-run any command with --verbose to see the full log, which usually points at the underlying cause.
